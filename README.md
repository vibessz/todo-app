# To-Do App

A full-stack to-do list app, built to learn React and Express by building something real instead of following tutorials.

## Features

- Create tasks
- View all tasks
- Update and delete tasks

## Tech stack

- **Frontend:** React (Vite)
- **Backend:** Node.js + Express
- **Data:** in-memory array (database coming soon)

## Roadmap

- [ ] Persistent database
- [ ] Good UI
- [ ] Auth
- [ ] Tags + priority sorting
- [ ] Deploy live

## Why I built this

Rebuilt an old Tkinter desktop to-do list as a full web app to learn full-stack development hands-on, project-first rather than through structured courses.
